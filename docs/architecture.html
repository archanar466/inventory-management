Factory Inventory Management System

System architecture, technology stack, and data flow overview

Technology Stack

Frontend

Vue 3 SPA

  • vue ^3.4 — Composition API
  • vue-router ^4.3 — client-side routing
  • axios ^1.6 — HTTP client
  • vite ^8.0 — dev server & bundler
  • Served on port 3000
Backend

FastAPI Service

  • fastapi — REST API layer
  • pydantic — request/response validation
  • uvicorn — ASGI server
  • CORS enabled for local dev
  • Served on port 8001
Data

In-Memory JSON

  • 7 JSON files in server/data/
  • Loaded once at startup by mock_data.py
  • No database — no persistence
  • Filtered in Python per-request
